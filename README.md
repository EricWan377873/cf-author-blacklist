# CF 拉黑出题人

一个用于 Codeforces 的 Tampermonkey 油猴脚本，自动屏蔽包含指定出题人的比赛。

## 功能

* **比赛列表**：自动隐藏 `Writers` 中包含黑名单用户的比赛。
* **兼容筛选**：支持 `/contests` 页面的筛选及动态更新。
* **指定比赛**：访问 `/contests/2261` 等指定比赛列表时，若存在黑名单出题人，自动跳转回 `/contests`。
* **自定义黑名单**：支持添加任意数量的 Codeforces 用户名，匹配时不区分大小写。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 新建脚本，粘贴 `CF 拉黑出题人.user.js` 的内容。
3. 保存并启用，打开 [Codeforces Contests](https://codeforces.com/contests) 即可。

## 配置

编辑脚本中的 `BLACKLIST` 数组：

```javascript
const BLACKLIST = [
    'chromate00',
    'Proof_by_QED',
    // 添加更多出题人
];
```

## 说明

仅在浏览器本地隐藏比赛，不影响 Codeforces 服务器上的数据。

## 写在最后：关于现在越来越狗屎的算法竞赛

说真的，现在部分算法竞赛的题目质量已经烂得让我忍无可忍了。

我他妈是来打算法竞赛的，不是来陪出题人玩猜谜游戏的。某些题目充斥着莫名其妙的构造、毫无直觉的结论和狗屁不通的思维跳跃。你说它难吧，难点又不在算法、不在知识、不在思维深度，而在于你能不能碰巧猜中出题人脑子里的那套鬼东西。

尤其是洛谷月赛的 [P17172《因果》](https://www.luogu.com.cn/problem/P17172)，简直是我近期见过最典型的屎山构造题之一。

我读完了它的[重构题解](https://www.luogu.com/article/94lofm9x)。整道题的解法就是不断维护已经构造好的部分，再对各种可能卡死的局面进行分类讨论、特殊处理、额外转移，最后还得精打细算地证明操作次数不会超限。

一堆特殊情况套着另一堆特殊情况，补完一个漏洞又冒出来另一个漏洞，最后终于拼出一个能通过的构造。

**这他妈到底有什么意义？**

最荒诞的是，题解作者甚至明确承认，构造思路参考了 GPT-5.6 Sol 的输出，而且仅凭出题人本人的能力，想出这种猎奇构造也是相当困难的。

我看到这里真的绷不住了。

连出题方都承认难以独立想出的猎奇构造，却被端上正式比赛，要求选手在有限的时间内自行摸索。选手到底是在训练算法思维，还是在尝试复原一套 AI 辅助产生的复杂构造？

**难道能把一堆特殊情况拼成一个正确算法，就说明这他妈是一道好题了？**

这种题除了考验选手对无数人为限制的耐受程度，究竟还想传递什么有价值的算法思想？我不否认它有正确的证明，但在我看来，它的复杂度主要来自出题人给自己制造的麻烦，而不是某种值得学习的深刻思想。

还有最近 Codeforces 的 [CF2261F2](https://codeforces.com/problemset/problem/2261/F2)，则是另一种形式的神经病猜猜题。

这道题的题解倒没有堆出那么多特判，但解法同样让我感到极其意义不明。你需要莫名其妙地想到把零的数量当成状态，再想到可以通过删除某些部分来切换状态，再想到保留三行、利用模三余数设计整套操作规则，最后还得用一大堆论证证明两个零不可能做到。

这当然是一套正确的构造。可问题是，**这他妈到底是怎么从题面自然推导出来的？**

从一个正常选手的视角来看，这不像是在循序渐进地解决问题，而更像是出题人事先搭好了一座机关城堡，然后把你扔进去，让你猜每一个隐藏开关在哪里。

猜中了，你就是天才；猜不中，你就只能对着题面干瞪眼。最后看完题解，才知道原来还可以这么他妈地设计规则。

我承认这可能是一种数学上的巧妙，但**巧妙不等于适合比赛，猎奇不等于有训练价值，能证明正确更不意味着值得拿来考人。**

我不反对难题，不反对构造题，不反对需要灵光一现的题目。我反对的是那些为了制造难度而制造难度、为了猎奇而猎奇、最后完全沦为猜出题人脑回路的狗屎题目。

一道优秀的难题，应该让人在理解题解后恍然大悟，觉得原来这些条件能够导出如此漂亮的结论。

而不是看完之后只想问一句：

**“操，这种毫无来由的鬼东西到底谁能在比赛里想出来？”**

更让我担忧的是，现在 AI 已经可以参与产生复杂的算法构造。P17172 的题解就明确披露了 AI 对构造思路的贡献。我不知道其他具体题目是否使用了 AI，也不打算把猜测当成事实。但这确实让我更加怀疑：当出题人可以借助工具探索出各种离奇而复杂的构造时，比赛是否会逐渐变成一场不对等的猜谜游戏？

工具可以帮助探索数学结论，这本身没有问题。但如果最终只剩下一坨几乎无法自然推导的特殊构造，再把它包装成比赛难题，那这种出题方式究竟对参赛者有什么意义？

对于 chromate00 和 Proof_by_QED 参与出题的部分 CF 比赛，我也已经彻底失去了耐心。我不想再浪费几个小时，对着一堆莫名其妙的构造疯狂 WA on 2，最后看完题解还得骂一句：**这他妈到底是什么狗屎玩意儿？**

我参加算法竞赛，是希望锻炼算法能力、逻辑推理和创造性思维，而不是练习猜测别人随手设计出来的奇怪规则，更不是陪着各种意义不明的构造浪费时间。

**难题不等于烂题，恶心人更不等于有水平。**

如果一场比赛越来越像出题人自娱自乐的脑筋急转弯大会，那我实在看不出来它究竟还有什么值得参加的必要。

我写这个脚本，就是因为我受够了。

既然 Codeforces 不提供屏蔽指定出题人的功能，那我就自己写一个。惹不起还躲不起吗？

**我的时间不是拿来给狗屎题目陪葬的。**

以上仅代表我个人的参赛体验和主观评价。如果你喜欢这类题目，那请继续享受；反正老子不奉陪了。
